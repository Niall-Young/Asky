# Asky 0.3.7 发布验证

[GitHub Release v0.3.7](https://github.com/Niall-Young/Asky/releases/tag/v0.3.7) 的构建号为 58，源码提交为 `9874102bcc82c1f6055d989188b12b1fca1b2536`。

## 构建与快速预览回归

- 从固定源码构建 MCP Bridge，运行 KulaCore 完整测试命令，通过。真实 Orca CLI 发现和合成追问两项测试按配置跳过。快捷键监听测试覆盖用户输入停用和超时停用时的恢复条件。
- XcodeGen 工程生成、Debug 和双架构 Release 构建通过。本地化检查覆盖 195 个 Swift 源文件。
- 在本机用发布源码中的 `PreviewShortcutCapture` 创建并启用系统事件监听，再调用 `invalidate()` 释放。通过 `CGGetEventTapList` 查询进程实际注册的监听，连续 20 次均从 0 增至 1，再回到 0。未测量长时间后台 CPU 占用。
- 文件快速预览回归的前三次直接运行分别停在启动器样本可见性、深色下 Swift 文件正文、关闭预览后保留选中项的断言。通过 Launch Services 启动同一测试应用，浅色和深色均通过。
- 系统快捷键回归通过 Launch Services 启动时缺少辅助功能权限。从已有权限的终端运行同一二进制并传入 `--file-preview --system-keys`，浅色和深色均通过，覆盖启动器和剪贴板打开预览、关闭预览及恢复焦点。
