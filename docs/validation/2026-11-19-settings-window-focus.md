# 设置窗口打开时的焦点

设置、AI 对话和图片预览统一通过 WindowPresentation 将新打开的窗口保持透明，取得键盘焦点并完成布局绘制后恢复原透明度。已显示的窗口在应用激活后置前。设置窗口关闭 AppKit 的默认窗口动画。

- 已运行 `xcodegen generate` 及 README 的 Debug 构建命令，构建成功。实际启动构建目录中的 Asky，从启动器按 `⌘,` 打开设置，通过辅助功能确认“通用 — Asky 设置”为前台应用的焦点窗口，并查看了窗口截图。
- 设置原生回归 `--dock-only` 通过。后台首次打开与关闭后重开均在窗口透明时取得键盘焦点，然后恢复完整不透明度。覆盖了 Dock 隐藏和显示两种模式。
- 设置原生回归 `--settings-chrome` 在浅色、深色下通过聚焦、失焦与恢复后的控件尺寸和对齐检查。桌面回归早期运行曾在焦点断言处中断，最终将两个设置回归依次运行，均通过。
- AI 对话原生回归 `--window-presentation` 通过，覆盖浅深色、首次打开、重复唤起及取消待激活窗口。
- `Packages/KulaCore` 的 `swift test` 通过，含 421 项 Swift Testing 测试和 5 项 XCTest。
