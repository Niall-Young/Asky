## 构建与回归

- 在独立、干净的工作树中运行 XcodeGen、Debug 构建和 arm64、x86_64 双架构 Release 构建。MCP Bridge 的 SwiftPM 构建通过。
- KulaCore 完整测试命令通过。真实 Orca CLI 发现和合成追问两项测试按配置跳过。
- 首轮本地化检查发现「图片」「移除」重复定义，且欢迎引导中的「开机自动在菜单栏就绪」缺少本地化键。修正后重新构建，197 个 Swift 源文件的静态文案键、中英文一致性和格式参数检查通过。
- 行内标签高度、退格删除和行首对齐三项原生回归通过。单行空态、纯文本、标签和混合输入均为 28 pt，加入标签前后基线均为 16 pt。设置按钮加载与完成态回归通过。
- 快捷键回归第一次在查找旧版 NSButton 时中止。将测试适配到当前的 HotKeyRecorderField 后，以发布版本的应用源码重跑，快捷键录制、持久化、冲突校验、恢复默认、剪贴板粘贴并保持窗口开启及其改绑分发均通过。测试修改提交为 `99f9589`。
