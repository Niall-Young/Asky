# Agent 交流文风去人机感调整

日期：2026-11-19。

## 变更

- `Packages/KulaCore/Sources/AgentHost/NativeAgentPrompt.swift`：
  - 调整交流语气描述，明确以熟悉用户的视角直接跟「你」平等聊天，用干净、平实、自然的现代中文打字交流，信息不全或看不清时坦白说目前不确定，避免「你们这类客户/开发者」等旁观或乙方口吻及老师/裁判架子。
  - 收紧并精简去 AI 腔与反面约束，避免长串负面举例在轻量模型（如 `deepseek-flash`）上引发规则稀释或反向触发：要求直白说事实和道理，少用比喻、类比、反问和“不是……而是……”修辞金句，既避免报告味和评论员文章（不先点评用户、不强行找补转折、不拔高收尾），也避免为了装接地气而硬加儿化音、土词或生硬缩写；少用“短语+冒号”引出正文，少用破折号，不用 `「」` 套概念词；聊完自然停住，不每轮在末尾抛反问，闲聊结尾也不突然切回顾问口吻推下一步。
  - 补足「层次清晰且自然」的正向结构约束：解释或分析时先用一句直白的话说出核心判断，再按主次合并展开，每段直接用完整句子开头，不用“先说结论：”“我的判断是：”“分开说”“一是……二是……三是……”或字数均等的平行板块。
  - 细化 Markdown 使用场景：去掉旧的 `###` 标题要求，明确不使用 `#`/`##`/`###` 标题层级，也禁止把独立整句或段首短语加粗当小标题或分段导语（如独立一行的 `**……**` 或 `**核心原因。**`）；常规聊天、讨论和分析默认用不加粗的短自然段顺着说；确需对比信息、列步骤或整理多条并列事实时使用简洁列表或表格，列表项直接写内容，不套前缀加粗标签。
  - 保留工作区中原有的 `<asky-reaction>` 表情克制调整。
- `docs/PRD.md` 与 `docs/agent-runtime.md` 同步上述交流风格与结构约定。
