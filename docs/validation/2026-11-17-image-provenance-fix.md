## 实际故障

- 用户截图中的两张失败图片来自“我想了解一下珠穆朗玛峰”这条回复。
- 读取对应原生会话快照：只有 user / assistant，没有任何找图调用；图片地址没有工具来源。
- 对其中 `Everest_North_Face.jpg` 的原始缩略图地址请求得到 HTTP 404。此次故障不是缓存命中旧图片。
- 先前配图实测只验证第一张图片，不能代表整条回复的所有图片可加载。

## 修复

- 最终图片必须有成功工具结果或当前用户原文中的 URL 作为来源；历史 assistant 内容不充当证据。
- 无来源或被模型改写的图链最多纠正一次；已结束的 imagesOnly 阶段不重新打开网页工具。错误草稿不发布、不进入叙述，也不保存为最终消息。
- 所有选中的有来源图片经 ToolService 下载、解码；最多三个并发，整批 5 秒预算，成功缩略图直接供界面缓存复用。失败图片及紧邻的独立图片来源链接移除，保留其余正文。
- 保留网络 SSE 接收，但正文事件在完整消息校验后发布。工具前叙述不携带未经校验的图片。
- 实测脚本从检查首张改为逐张检查，并记录候选与每张图片的解码结果。
