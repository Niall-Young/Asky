# AI 对话回到底部的滚动动画

在 macOS 27.0.1 上用 Debug 构建产物运行原生窗口回归。旧实现对普通长回复和多条历史消息也能采到中间位置，本机未稳定复现用户看到的瞬移。修复后，按钮直接沿实际对话视口滚动，目标随内容高度更新，沿用定位原回复的 220 毫秒减速动画。

- 在 `Packages/KulaCore` 运行 `swift test`，通过。运行 `xcodegen generate` 并按 README 的命令构建 Asky Debug，通过。
- 运行 `python3 App/Tests/run-agent-reply-regression.py --reading-scroll`。通过原生鼠标事件点击按钮，按 16 毫秒间隔采样。对 70 段长回复以及加上 `--scroll-history` 的 30 条历史消息场景，分别在默认和强制 `--preview-macos14` 分支验证。四种场景共 12 次完整点击，每次在行程的 5% 至 95% 之间采到 7 至 8 个不同位置，结束时视口与文档底部相差 0 pt。
- 四种场景均在点击 70 毫秒后发送开始手动滚动通知并移动视口，400 毫秒后仍停在读者选择的位置。
- 同一回归程序的 `--reply-navigation` 在两个分支均通过，覆盖点击引用卡片、手动打断定位和从历史分页返回最新页。

兼容分支在当前系统上强制运行。此次未在 macOS 14 真机或开启“减少动态效果”的环境中验证。
