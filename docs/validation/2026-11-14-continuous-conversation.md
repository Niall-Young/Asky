# 持续对话与历史清理

日期：2026-11-14。

## 实现

- Agent 各入口统一显示分页时间线；移除新对话按钮和快捷键设置。历史搜索正文，定位原消息；提交前返回最新历史。
- 原会话 ID 保留为来源分段，无破坏性消息迁移；新请求每轮使用独立分段，历史按需组装，不能重新载入旧快照恢复已删上下文。
- 注册仅应用内 Agent 可用的 history_search / history_read，不依赖个人记忆开关，不向 Launcher 或 MCP 暴露。
- 手动删除按完整轮次；旧会话可删除其中一轮。期限按用户轮次提交时间计算，清理旧前缀及全文索引、附件、执行记录、活动正文与旧标题。
- 清空全部历史保留长期记忆和当前草稿引用；回收历史遗留孤立记录与文件。派生快照清理通过持久队列重试。
- 自动清理在无任务时进行，任务结束补做。清空时再次校验在途任务；发送与清理通过宿主状态互斥。提炼回写检查 history.revision，删除期间已发出的提炼不能回写旧资料。
- 没有额外持久化独立的模型任务摘要库；跨话题续接目前依赖最近正文、保留的工具状态和模型按需历史检索。不会为迁移历史批量调用模型。

## 限制

没有使用真实模型验证跨天多话题续接质量，也没有操作日常用户历史或替换 /Applications 中的安装。清空确认弹窗未完成 GUI 点击验收；尝试继续读取回归窗口时 UI 服务超时。模型请求已经外发的数据无法通过本地删除撤回。
