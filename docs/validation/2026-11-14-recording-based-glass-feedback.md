# 录屏参考的玻璃按钮反馈

## 已确认范围

用户提供 12.802 秒、1206×2622、60 fps 的 iOS 录屏，随后明确选择“以录屏效果为准，允许定制交互，但保留 Asky 原外观”。录屏仅本地抽帧分析，没有上传。按中性像素阈值粗测，首个圆形按钮从约 132 px 放大至 170 px，松手后有一次缩小再回到原尺寸；这只是画面估计，不是系统参数。

采用定制 `GlassPointerFeedback`，不宣称为 macOS 自带动画。原有材质、尺寸、图标与布局不变，不加入方块高亮、内部分隔线或新玻璃底板。聊天顶部仍为原来的无边框 NSButton 和 72×36 胶囊；整个胶囊统一反馈。头像、回到底部、发送和启动器底部操作接入同一反馈；聊天普通图标保留原有悬停形状，仅加入按压反馈。共用的启动器操作样式也用于剪贴板底部。

首版按触摸参考最多放大 29%，用户实际查看后指出幅度过大，已收小到 `1 + min(0.06, 3 / 最长边)`：36 pt 圆形最多 6%，72 pt 胶囊约 4.17%，最长边最多增加 3 pt。悬停不缩放；玻璃使用同形状加色叠层提亮（hover 0.055、press 0.16），按下 100 ms easeOut，释放 spring response 0.34 / damping 0.42。减少动态效果时关闭缩放，禁用时无反馈。AppKit 鼠标跟踪与原 action 保留，动作不等待动画结束。
